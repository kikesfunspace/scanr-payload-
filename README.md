HI! This is the repo dedicated to working on the SCANR mission — 
target detection, distance calculation experiments, and all that good 
stuff. Feel free to create your own notebook and 
add to the work as you go.

Any doubts, feel free to reach out to me (the admin).

## Folder Guide

- **detection/** — code for finding the target in an image (color/shape detection)
- **docs/** — notes, decisions, trade studies, anything written
- **hardware/** — sensor/camera/IMU test scripts
- **learning/** — practice space to learn Python/Git, mess around freely here
- **notebooks/** — Colab notebooks, save your experiments here
- **test_images/** — reference photos used for testing
